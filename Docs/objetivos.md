## Definir objetivos claros

### Objetivo general

El objetivo principal a nivel de empresa es desarrollar una aplicación que funcione de manera óptima y que facilite la búsqueda de clientes por parte de empresas de construcción y reformas, y viceversa que los clientes puedan encontrar una constructora de manera más rápida y les lleguen varias propuestas de distintas constructoras.

### Objetivos específicos

- Crear una aplicación sencilla e intuitiva tanto para usuarios como para empresas.
- Permitir que los usuarios publiquen solicitudes relacionadas con construcción y reformas.
- Facilitar que las empresas puedan responder con presupuestos y propuestas.
- Centralizar las solicitudes y respuestas en una sola plataforma.
- Contar con una base de datos que permita guardar las peticiones, empresas y usuarios que entraran a la aplicación.

### Objetivo adicional

Definir un control más eficiente para los empleados que tengan acceso administrativo, incluyendo:

- Roles para la aplicación.
