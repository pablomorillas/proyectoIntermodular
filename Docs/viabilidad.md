## Justificación de viabilidad

### Viabilidad técnica

El desarrollo del proyecto es técnicamente viable, ya que se puede implementar con tecnologías accesibles, actuales y de uso extendido.

- **Frontend:** React.js para la interfaz de usuario.
- **Backend:** Spring Boot (Java) para la lógica del servidor y gestión de la API REST.
- **Base de datos:** MySQL para el almacenamiento estructurado de información.
- **Infraestructura:** La base de datos se alojará en AWS y la API se desplegará mediante Render, permitiendo una mayor disponibilidad y facilidad de despliegue.

Estas tecnologías son gratuitas o con versiones open source, lo que facilita el desarrollo inicial y asegura que el proyecto no dependa de software costoso.

### Viabilidad económica

En principio, la aplicación no requiere de un presupuesto elevado para ser desarrollada, debido al uso de herramientas y frameworks open source.

Los únicos costes directos provendrían de la infraestructura en la nube:

- **Servidor AWS:** pago mensual ajustable según el nivel de uso y tráfico.
- **Escalabilidad:** en caso de un aumento considerable de peticiones, se podrá mejorar la infraestructura gradualmente, sin necesidad de una gran inversión inicial.

Esto hace que el proyecto sea económicamente accesible y adaptable a las necesidades de la empresa.

### Viabilidad operativa

Respecto a un punto de vista profesional, este proyecto es viable con los recursos disponibles.

La parte más compleja del proyecto sería la parte de back-end debido a la lógica que hay detrás del sistema de la base de datos. Sin embargo, cabe mencionar que debemos de tener en cuenta también la parte de front-end para hacer la aplicación fácil de usar tanto para empresas como para usuarios.

En cuanto al mantenimiento, el mantenimiento inicial será reducido, aunque sí serán necesarias actualizaciones y mejoras periódicas para la aplicación. Aunque sí que será necesario añadir funciones nuevas dependiendo de las necesidades de la empresa, por no mencionar que también será necesario mantener la infraestructura del servidor.
