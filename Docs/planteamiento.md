## Planteamiento del problema y justificación

### Proyecto: Aplicación para empresa de construcción

Este proyecto se basará en el desarrollo de una aplicación destinada a aquellos usuarios que la usen y a su vez a las empresas que quieran dar sus presupuestos para estos usuarios.

Las principales necesidades que abordará la aplicación son:

- Identificar los requerimientos de los clientes/usuarios.
- Facilitar la gestión de solicitudes y presupuestos entre usuarios y empresas.
- Que las empresas ofrezcan presupuestos a los usuarios.

La importancia de este proyecto radica en que los usuarios hacen peticiones a empresas constructoras sobre sus problemas y/o necesidades que requieren. Los usuarios hacen encargos pidiendo presupuestos a estas empresas y ellos se encargan de darles presupuesto, si los usuarios aceptan, la empresa podrá prestarles ese servicio.

El impacto será significativo, ya que el sistema se diseñará para ser claro y sencillo, de manera que cualquier usuario pueda comprenderlo.

En conclusión, este proyecto tiene como finalidad ser lo más realista posible, simulando una aplicación que podría ser solicitada en un entorno empresarial real, con la intención de facilitar la comunicación y gestión de solicitudes entre usuarios y empresas.
